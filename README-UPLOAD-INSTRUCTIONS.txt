# Sammy Studio — Ken Olsen Auto Repair case-study package

This ZIP contains the new case-study page and the homepage project-card snippet.

## Files
- `ken-olsen-auto-repair.html` — standalone case-study page
- `case-study.css` — styles for the case-study page
- `homepage-card-snippet.html` — project card to insert into `index.html`
- `homepage-card.css` — styles for that homepage card

## Add it to GitHub
1. Open `Samueloboba/sammy-studio` on GitHub.
2. Extract this ZIP on your device first. GitHub's web uploader does not unpack ZIP files.
3. Upload `ken-olsen-auto-repair.html`, `case-study.css`, and `homepage-card.css` to the repository root (the same level as `index.html` and `styles.css`).
4. Open `index.html` and paste the contents of `homepage-card-snippet.html` inside the existing `<div class="project-grid">`, ideally after the Comic Forge card.
5. Open `styles.css` and append the contents of `homepage-card.css` to the bottom.
6. Commit the changes. Vercel should redeploy from the connected GitHub repository.

## Notes
- The case-study page reuses the existing `styles.css` and `script.js`.
- The live client website link is `https://ken-olsen.vercel.app`.
- This package intentionally does not replace your existing homepage, CSS, JavaScript, images, or videos.
- The project narrative is kept factual and avoids inventing performance metrics or client results.
