# Sammy Studio Portfolio — V1

A responsive, animated, no-build static portfolio. Includes home, work, about, skills, and contact sections.

## Preview locally
Open `index.html` in a browser.

## Deploy to Vercel
1. Create a GitHub repository named `sammy-studio-portfolio`.
2. Upload these three files plus this README to the repository root.
3. In Vercel, choose **Add New → Project**, import the GitHub repository.
4. Framework preset: **Other**. Build command and output directory can remain blank/default; the site is static.
5. Click **Deploy**.

Before launch, replace the demo email in `index.html`, update project cards with real work, and optionally change the year.
